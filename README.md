# Bibi Ashik - Portfolio

A minimal, dark-themed developer portfolio built with Vanilla HTML, CSS, and JavaScript. 

### Features
* **Terminal Aesthetics:** Clean, hacker-inspired UI with typewriter and decryption text effects.
* **Responsive Design:** Fully fluid CSS Grid and Flexbox layouts for mobile, tablet, and desktop views.
* **Live GitHub Integration:** Fetches real-time repository and contribution data directly from the GitHub API.
* **Performance Focused:** Zero heavy frameworks, resulting in instant load times and buttery smooth animations.
